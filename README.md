# HabitTracker

HabitTracker - это внутренний API для отслеживания привычек, интегрированный с Telegram. Основанный на книге Джеймса Клира "Атомарные привычки", он поможет
вам сделать полезные привычки частью вашей жизни.

## Installation

1. Clone the repository:
```commandline
git clone https://github.com/mikhailsorochinskiy/habit_tracker.git
```
2. Install project dependencies:
```commandline
poetry install
```
